Pendo Launcher: deployment and configuration guide

Use this guide to decide how to deploy and configure the Pendo Launcher browser extension across your organization. You’ll choose browsers and operating system to see recommended deployment options and weigh the pros and cons of each path.

Before you deploy

Coordinate with your teams and confirm these items before rolling out the Pendo Launcher.

  • Align with developer, security, privacy, and IT teams on the deployment approach
  • Choose which browsers (Chrome 57+, Edge, or Firefox) and operating systems (Windows, macOS) to target
  • Select a Visitor ID source that is available to your endpoint management tools and approved by security and privacy
  • Plan what visitor metadata (e.g. role, location) you will collect
  • Ensure JavaScript is enabled and not blocked by security software on target devices

      Manually install the Pendo Launcher for testing and demoing

      Check your dataEnvironment value

      If your subscription is stored in a different data environment (e.g. EU for GDPR), you must set the dataEnvironment property when configuring the Launcher. Default is io; other values include us1, eu, jpn, and au.

      Find it in Pendo under Settings > Subscription settings > Extension. Double-check that the value matches your subscription's data environment.
